# Public portfolio website

This repository hosts the generated static website for [g14uok](https://github.com/g14uok). The website is built from the private [portfolio-source](https://github.com/g14uok/portfolio-source) repository whenever a commit is merged to its `master` branch.

Do not edit generated site files here. The private repository's build workflow replaces them on the next publish. The GitHub Pages workflow in `.github/workflows/pages.yml` deploys each update.

After enabling **Settings → Pages → Build and deployment → GitHub Actions**, the site is available at <https://g14uok.github.io/portfolio-site/>.
