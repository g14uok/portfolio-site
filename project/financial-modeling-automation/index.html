Financial Modeling Workflow Automation

Turns source data and spreadsheet-based scenario calculations into a repeatable Python and AWS workflow.

PythonPandasNumPyAWSData Science

High-Level Summary

This project replaces a manual spreadsheet-based financial modeling workflow with a repeatable Python and AWS data pipeline. I contributed data preparation, scenario-modeling automation, cloud workflow development, and training for portfolio managers.

The Challenge

Complex calculations and source data were handled through unstructured spreadsheets, making the workflow difficult to repeat and maintain. The replacement needed to ingest data from multiple sources, transform it consistently, and produce scenario-based growth model outputs.

Architecture & System Overview

Source data is collected and transformed by Python workflows, then processed through event-driven AWS services to generate modeling outputs. The resulting workflow separates data preparation, scenario calculations, and output delivery from manual spreadsheet steps.

  • Taught Python and data science fundamentals to portfolio managers using the tools.

Key Engineering Trade-offs & Lessons

  • Moving formulas into code improves repeatability and reviewability, while requiring users to maintain clear assumptions and input definitions.
  • Event-driven cloud services support automation, but add orchestration and operational concerns compared with a local spreadsheet.
  • Reliable automation depends on explicit input definitions, data validation, and scenario assumptions.
