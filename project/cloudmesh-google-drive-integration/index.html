CloudMesh Google Drive Integration

Adds Google Drive file operations to a provider-neutral cloud-storage interface developed as graduate open-source work.

PythonGoogle Drive APICloud StorageOpen Source

High-Level Summary

This graduate open-source contribution adds Google Drive file operations to the CloudMesh multi-cloud storage interface. I implemented provider integration so users can perform common storage actions through a shared abstraction instead of calling provider-specific operations directly.

The Challenge

Cloud providers expose different APIs, authentication models, and file metadata. A common storage interface must normalize those differences while still supporting useful provider operations.

Architecture & System Overview

CloudMesh presents a unified storage interface and delegates file operations to a provider adapter. The Google Drive adapter translates those operations into Google Drive API requests and returns normalized results.

Key Engineering Trade-offs & Lessons

  • A provider-neutral interface simplifies common workflows, while provider-specific capabilities and limits still need explicit handling.
  • The abstraction improves portability but adds an adapter layer that must preserve authentication and operation semantics.
  • Provider adapters preserve each service's authentication and file semantics behind the shared interface.
