High-Level Summary

This academic game-analytics project combines purchase, session, and user records to study customer lifetime value and player segmentation. The notebook aggregates behavior by user and explores regression approaches for estimating value and supporting marketing analysis.

The Challenge

Game activity is recorded across purchase, session, and user tables, so useful analysis depends on joining events into consistent player-level features. The project explores how those features can support value estimation and behavioral segmentation.

Architecture & System Overview

The notebook aggregates purchase and session records by user identifier, joins them with user data, and applies regression approaches including linear regression and Lasso. The resulting features and estimates support player-value and segment analysis.

Key Engineering Trade-offs & Lessons

  • Player-level aggregation simplifies behavioral analysis but depends on careful feature definitions and time windows.
  • Linear and regularized models provide useful baselines, while more complex models require stronger validation and interpretability checks.
