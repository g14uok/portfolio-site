High-Level Summary

This academic analysis explores customer characteristics associated with credit-card default using exploratory analysis and logistic regression. The repository is titled SQL/NoSQL, while its available notebooks focus on Python and R data analysis and modeling.

The Challenge

The project asks which customer characteristics are associated with default and how those relationships can be analyzed from a credit-card dataset. It needs data preparation, interpretable modeling, and evaluation views that expose both model behavior and class imbalance.

Architecture & System Overview

The notebooks load the UCI credit-card dataset, prepare features, perform exploratory analysis, and fit logistic regression. Precision-recall and ROC analyses are used to examine classification behavior.

Key Engineering Trade-offs & Lessons

  • Logistic regression provides an interpretable baseline but may not capture nonlinear relationships without additional features or models.
  • Precision-recall and ROC views offer complementary perspectives on a potentially imbalanced classification problem.
  • The README frames the coursework as SQL/NoSQL, while the available implementation primarily demonstrates Python/R analysis.
