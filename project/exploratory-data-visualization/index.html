High-Level Summary

This academic repository collects exploratory visual-analysis projects implemented in R and ggplot2. The work examines several datasets and questions, including breast-cancer data, voter-switching hypotheses, and development indicators.

The Challenge

The repository is a collection of separate analyses rather than one deployed product. Each study needs a clear question, data preparation, appropriate statistical summaries, and visualizations that make patterns easier to inspect.

Architecture & System Overview

R scripts and R Markdown notebooks load or prepare datasets, run exploratory or statistical analyses, and produce plots and model summaries. The studies are independent and use different data sources and methods.

Key Engineering Trade-offs & Lessons

  • The repository is a collection of focused analyses, so each study needs its own context and interpretation.
  • Model-based studies can test specific relationships, while conclusions remain bounded by the data and assumptions used.
  • Because the studies use different datasets and methods, interpret findings within each study rather than as one combined model.
